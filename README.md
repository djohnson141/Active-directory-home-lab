# Active-directory-home-lab

## Summary

I'm building a simulated corporate Active Directory environment to learn identity and access management concepts like user provisioning, account management, and least-privilege access

## Goals

- Learn active directory basics
- Create and manage users
- Create security groups
- Practice role based access control (RBAC)
- Document onboarding and offboarding
